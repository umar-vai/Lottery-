About DRAW//01

A public multiplayer draw simulator built to test account-based ticket selection, event-specific ticket pools, ranked winners and virtual-credit rewards.

What this project is

DRAW//01 is a software demonstration for event-based number-ticket draws. Visitors can view public event information, and authenticated users can submit simulated number selections to individual events.

How it works

  • Every event maintains its own isolated pool of submitted tickets.
  • The admin configures how many winners an event will have and the virtual-credit prize for each rank.
  • An event may use a scheduled cutoff and draw time or remain open until an admin triggers its draw.
  • At draw time, winner tickets are selected only from tickets already submitted to that exact event.
  • The system refuses to draw if there are fewer tickets than the configured number of winners.
  • Ranked results and virtual-credit ledger movements are stored in the database.

Technology

The public frontend is hosted on GitHub Pages. Authentication and database services are provided through Supabase, with Google OAuth used for account sign-in.

Important limitation

This is a simulation/testing project only. It does not sell tickets, accept payments, facilitate wagering, or award real-world prizes.
