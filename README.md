# DRAW//01 — Powerball-style Lottery Simulator

A minimal, responsive static web app inspired by the current Powerball number format.

## What it does

- Quick Pick: generates 5 unique white balls from 1–69 and 1 red Powerball from 1–26
- Manual number picker
- Animated simulated draw
- Ticket-vs-draw match checking
- Recent draw history stored locally in the browser
- Mobile-friendly dark tech UI
- No backend, database, API key, account, payment, ticket sale, or wagering system

## Run locally

Open `index.html` in a browser.

## GitHub Pages

A Pages workflow is included at `.github/workflows/pages.yml`.

For the first deployment, open:

`Repository Settings → Pages → Build and deployment → Source → GitHub Actions`

Then run the workflow (or make any commit to `main`). The expected public URL is:

`https://umar-vai.github.io/Lottery-/`
