About DRAW//01

A public multiplayer draw simulator built to test account-based ticket selection, scheduled server draws, realtime results, and verifiable draw mechanics.

What this project is

DRAW//01 is a software demonstration inspired by the structure of Powerball-style number draws. Visitors can view public draw information, and authenticated users can submit simulated number selections for scheduled test draws.

How it works

  • Five unique white numbers are selected from 1–69.
  • One Powerball-style number is selected from 1–26.
  • Tickets close automatically before a scheduled draw.
  • The backend generates one shared result for all users.
  • Results, simulated prize tiers, and draw history are stored in the database.
  • Cryptographic commitment and seed-reveal mechanics are used to make completed draws independently verifiable.

Technology

The public frontend is hosted on GitHub Pages. Authentication and database services are provided through Supabase, with Google OAuth used for account sign-in.

Important limitation

This is a simulation/testing project only. It does not sell tickets, accept payments, facilitate wagering, or award real-world prizes.
