DRAW//01SUPPORT PHONE BRIDGE

Link your bKash SMS to the cloud.

This phone bridge is for development-support verification only. It sends parsed received-money transaction data to DRAW//01 so the matching supporter can claim separate Support Points.

Support Points cannot be used for draw tickets, odds, prize eligibility, cash withdrawal or cash conversion. The cloud does not store the full SMS text.

In Admin Panel → Overview → Phone Bridge, create a phone token. Paste that one-time token here. It is stored only in this phone's browser storage.
