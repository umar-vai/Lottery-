About Game Zone

A virtual-credit simulation platform combining event-based draws with instant games.

What this project is

Game Zone is a software demonstration and testing platform. Authenticated users can join virtual-credit events, keep ticket history, use referral features, and play server-authoritative instant games such as Neon Fortune Slots.

How it works

  • Every event maintains its own isolated pool of submitted tickets.
  • Instant games use protected server-side functions and the same virtual Draw Credit balance.
  • Slot outcomes are generated on the backend using fixed versioned odds; the browser only animates the result.
  • Game bets, payouts, ticket purchases, prizes, and admin adjustments are recorded in the credit ledger.
  • Development Support Points remain separate and cannot be used for gameplay.

Technology

The public frontend is hosted on GitHub Pages. Authentication and database services are provided through Supabase, with Google OAuth used for account sign-in.

Important limitation

This is a simulation/testing project only. Virtual Draw Credits have no cash value and cannot be withdrawn. The site does not sell cash-redeemable game credits, accept wagers, or award cash prizes.
